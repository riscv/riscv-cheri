==== CBO.ZERO ({cheri_base_ext_name})

Synopsis::
Store zeros to the full set of bytes corresponding to a cache block

Mnemonic::
`CBO.ZERO 0({cs1})`

Encoding::
[wavedrom, ,svg,subs=attributes+]
....
{reg: [
  {bits: 7,  name: 'opcode',    attr: ['7','MISC-MEM=0001111'],  type: 8},
  {bits: 5,  name: 'funct5',    attr: ['5','CBO=00000'],     type: 2},
  {bits: 3,  name: 'funct3',    attr: ['3','CBO=010'],  type: 8},
  {bits: 5,  name: 'rs1{ne}0',  attr: ['5','base'],     type: 4},
  {bits: 12, name: 'funct12',   attr: ['12','CBO.ZERO=000000000100'],   type: 3},

include::load_store_creg0.adoc[]

Description::
A CBO.ZERO instruction performs stores of zeros to the full set of bytes corresponding to the cache block whose effective address is the base address specified in `{cs1}`.
An implementation may or may not update the entire set of bytes atomically, although each individual write must atomically set the {ctag} of the corresponding naturally aligned YLEN-bit memory location to zero.
The authorizing capability for this instruction is `{cs1}`.
+
This instruction requires that `{cs1}` grants <<w_perm>> and that the entire cache block is within the bounds of `{cs1}`.
