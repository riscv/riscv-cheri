NOTE: {rvy_zcy_ext_name} is only available on {cheri_base64_ext_name} (and in {cheri_cap_mode_name} when {cheri_default_ext_name} is implemented).
On {cheri_base64_ext_name}, {rvy_zcy_ext_name} reuses the encodings of Zcd, so Zcd is only available in {cheri_int_mode_name} when {cheri_default_ext_name} is implemented.
Zcmp and Zcmt are incompatible with {cheri_base64_ext_name}.
